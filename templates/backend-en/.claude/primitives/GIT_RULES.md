# GIT_RULES

## Git Rules

### Forbidden Actions

1. **Never push** without explicit permission
2. **Never use Co-Authored-By: Claude**
3. **Never force push to main/master**

### Commit Message Format

```
type: short description

- feat: new feature
- fix: bug fix
- refactor: code restructuring
- docs: documentation
- test: tests
- chore: other
```
