# GIT_RULES

## Git წესები

### აკრძალული მოქმედებები

1. **არასდროს დაფუშო** ჩემი ნებართვის გარეშე
2. **არასდროს გამოიყენო Co-Authored-By: Claude**
3. **არასდროს force push main/master-ზე**
