# Global Claude Code Settings

Files that go in `~/.claude/` (user home directory) and apply to ALL projects.

## Setup

```bash
# Copy to home directory
cp CLAUDE.md ~/.claude/CLAUDE.md
```

**Windows path:** `C:\Users\<username>\.claude\CLAUDE.md`
**Mac/Linux path:** `~/.claude/CLAUDE.md`

## What it does

Forces Claude to always check and follow project-level `.claude/` conventions
(primitives, agents, skills) before making any code changes.
