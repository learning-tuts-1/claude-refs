# Explain Code

კოდის ახსნა — ვიზუალური დიაგრამებით, ნაბიჯ-ნაბიჯ walkthrough-ით და "ხაფანგების" გამოყოფით.

## ახსნის სტრუქტურა

### 1. მოკლე მიმოხილვა
ერთ-ორ წინადადებაში — რას აკეთებს ეს კოდი და რატომ არსებობს?

### 2. დიაგრამა (ASCII Art)
**ყოველთვის დახატე** კოდის flow, სტრუქტურა ან კომპონენტებს შორის კავშირი.
ტიპები: Flow diagram, Component Tree, State Machine, Data Flow.

### 3. ნაბიჯ-ნაბიჯ Walkthrough
ეტაპობრივად ახსენი რა ხდება, როგორც კოდი სრულდება.
ფორმატი: **ნაბიჯი N — Name:** აღწერა...

### 4. ხაფანგები (Gotchas)
გამოყავი ნიუანსები სადაც დეველოპერები ხშირად უშვებენ შეცდომას.
ფორმატი: Problem → Cause → Fix

## ანალოგიები რთული კონცეფციებისთვის

როცა კონცეფცია რთულია, გამოიყენე ანალოგია:
- **Closure** = "სნეპშოტი" (ფუნქცია იმახსოვრებს გარემოს)
- **Event Loop** = რესტორნის მიმტანი (არ ელოდება კერძს)
- **Virtual DOM** = Word დოკუმენტის diff/patch
- **useMemo** = "კალკულატორის შენიშვნა" (არ ითვლი თავიდან)

## საუბრის ტონი

- **მეგობრული და სასაუბრო** — არა ლექცია, არამედ კოლეგასთან საუბარი
- **"შენ" მიმართვა** — "როცა შენ გამოიძახებ ამ ფუნქციას..."
- **აღიარე სირთულე** — "ეს ცოტა tricky-ა, მოდი ნაბიჯ-ნაბიჯ"
- **რეალური მაგალითები** — "ეს ხშირად გვხვდება როცა..."
